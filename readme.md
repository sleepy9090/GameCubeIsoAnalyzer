Update to add write support, all fields can now be edited<br/>

January 12, 2015 Version 1.0.0.30103<br/>
Open a GameCube ISO/GCM and the following information is read from it:<br/>
Filename<br/>
Game Name<br/>
Console ID<br/>
Game Code<br/>
Country Code<br/>
Maker Code<br/>
Disc ID<br/>
Version<br/>
DVD Magic Word<br/>
Debug Monitor Offset (dh.bin)<br/>
Address to Load the Debug Monitor<br/>
Offset of the Main Executable DOL (bootfile)<br/>
Offset of the FST (fst.bin)<br/>
FST Size<br/>
Max FST Size<br/>
